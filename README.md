# AgriConnect – A One-Stop Solution for Farmers 🌾🚜

## 🌟 Key Features:
✅ Sell Crops at Fair Prices – Farmers can list their produce, and vendors can purchase directly.

✅ AI-Powered Farming Assistance – Get real-time insights, weather updates, and best farming practices.

✅ Marketplace for Agricultural Tools – Buy and sell farming equipment, seeds, and machinery.

✅ Seamless Vendor-Farmer Connection – Secure transactions and easy communication.

AgriConnect is revolutionizing the agricultural sector by making trade more accessible, transparent, and profitable for farmers.

## Tech Stack
MongoDB · Express · React (Vite) · Node.js · Socket.IO

## Getting Started
1. **Backend:** `cd backend`, copy `.env.example` to `.env`, fill it in, then `npm install && npm run dev`
2. **Frontend:** `cd frontend`, copy `.env.example` to `.env`, then `npm install && npm run dev`
3. Open http://localhost:5173

## Deployment
Frontend on Vercel/Netlify (root directory `frontend`), backend on Render/Railway (root directory `backend`, or use `render.yaml`), database on MongoDB Atlas.
